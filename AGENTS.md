# KaKa — agent notes

KaKa is a **Linux-only, local-only** launcher for user-supplied Windows game
trainers. It runs a trainer `.exe` inside the Proton prefix of the game that is
currently running. Fork of [wyyadd/LaLa](https://github.com/wyyadd/LaLa)
(AGPL-3.0 — keep the license and the upstream credit).

## Hard rules

- Linux only. Do not add Windows/macOS/mobile/web targets or `Platform.isWindows` branches.
- Local only. No online catalogue, telemetry, update checks or network calls.
  Users add their own trainers; KaKa never downloads executables.
- Never auto-launch a trainer the user did not explicitly add.
- Launch processes with argument lists (`Process.start(exe, [args])`), never via a shell string.

## Toolchain

- Flutter version is pinned in `.fvmrc` (currently 3.41.7). Dev SDK on the
  maintainer host: `~/.local/share/flutter-sdk/<version>`, symlinked as `flutter`/`dart`.
- Formatter page width is 150 (`analysis_options.yaml`).

## Verify before commit

```sh
flutter pub get
flutter analyze          # must report no issues
flutter test             # unit tests live in test/
flutter build linux --release   # → build/linux/x64/release/bundle/kaka
```

## Layout

| Path | Purpose |
|---|---|
| `lib/util/proton.dart` | Pure Steam/Proton discovery logic (unit-tested, no Flutter imports) |
| `lib/util/game_launcher.dart` | UI-facing launch flow, process spawning, trainer tracking |
| `lib/util/storage.dart` | JSON persistence in `$XDG_DATA_HOME/io.github.spaghetticodez.kaka/` |
| `lib/l10n/*.arb` | Strings (en template; de, zh). Regenerated by `flutter gen-l10n` / build |
| `test/` | Unit tests with fixture `config_info` / `libraryfolders.vdf` samples |

Packaging (`dist/`) is undecided; the files there are legacy LaLa recipes and are not wired into CI.
